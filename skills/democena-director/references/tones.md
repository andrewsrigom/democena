# Tones

- `polished`: restrained claims, longer holds, clean type and soft transitions.
- `cinematic`: one strong value claim, large type and deliberate progression.
- `app-store`: benefit-led copy, clear product framing and smooth movement.
- `deadpan`: minimal copy, sparse layouts and hard or slow cuts.
- `custom`: translate explicit user direction into concrete scene rules.

Resolve conflicts in this order: verified evidence and safety, explicit user constraints, configured brand, profile defaults, tone defaults, neutral defaults. Tone never overrides facts, brand rules, readability or accessibility.
