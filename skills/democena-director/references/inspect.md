# Inspect

Answer these before writing scenes:

1. What does the product do?
2. Who is the demo for?
3. Which outcome matters most?
4. What is the strongest truthful hook?
5. Which real action demonstrates the value?
6. Which recorded result proves it?
7. Which element best represents the product?
8. Which profile and tone fit the request?
9. What is the shortest readable duration?

Resolve brand inputs in this order: explicit project branding, imported asset, source CSS or metadata, neutral defaults. Resolve locale from explicit user choice, application language, then approved copy. Use `und` with a warning when unknown.

The initial delivery format is landscape MP4, 1920×1080, 30 fps, H.264 yuv420p, without an audio stream. Report vertical, square, narration and music requests as unsupported by the initial profile.

Prefer test accounts and synthetic records. Do not put credentials or secrets in direction data. If a captured frame contains sensitive data, recapture it safely or use a supported crop that excludes it completely.
