# Review

Run `democena_validate_project`, then start a preview render. Reuse a matching nonterminal job if the server returns one.

Inspect:

- every settled scene still;
- `review-contact-sheet` for sequence and pacing;
- every `transition-*` image for visual pops or unintended overlap;
- `review-poster` for a useful, settled product frame;
- `quality.json` for reading time, contrast, preview coverage and media findings.

Democena checks authored copy at three words per second with minimum settled holds, and checks white-on-accent text at 4.5:1. Text inside captured screenshots still requires visual inspection.

Fix every `error` before final rendering. Assess each `warning`; recorded UI legibility cannot be proven without image or OCR analysis. Never claim review is complete from an exit code alone.
